🖼️ MISSION 01

Start with the image basics

UNIT 6 · UNIT 7

1. Basic and advanced image manipulation

Covers: familiarizing with an image editing application; basic techniques; artistic distortion effects; drawing and painting; combining text, graphics and images; uploading and sharing images.

What you should learn

An image editor lets you change a picture while keeping its message clear. Common tasks include cropping, resizing, adjusting brightness, using layers, adding text and exporting a finished image. GIMP is one example of an open-source image editor.

Lesson A — Get familiar with the editor

  1. Open the image editor and identify the canvas, toolbox, menus, layers panel and color controls.
  2. Open a practice image using File → Open (menu wording can differ).
  3. Save a working copy with a new filename so the original remains unchanged.
  4. Try selecting, moving and zooming the canvas. Undo a test action to learn how to recover from mistakes.

Lesson B — Crop, resize and adjust

  1. Crop: choose the crop tool, frame the subject, and apply the crop. Remove distractions without cutting off important details.
  2. Resize: open the image-size option and enter the required dimensions. Keep the width-to-height proportions linked when appropriate to avoid stretching.
  3. Adjust: make small brightness, contrast or color adjustments. Compare the result with the original before accepting changes.
  4. Export: use JPEG for many photographs and PNG when transparency or crisp graphic edges are needed. Keep an editable project copy if the app supports it.

Lesson C — Layers, text and effects

  1. Create a new layer before adding text or shapes. Layers let you edit elements separately.
  2. Add a short heading and keep it readable against the background.
  3. Apply a subtle filter or artistic distortion to a duplicate layer, then compare it with the untouched version.
  4. Use drawing or painting tools to add simple shapes or accents. Keep effects purposeful rather than distracting.

Lesson D — Combine and share images

  1. Place a background image on one layer and a separate graphic or logo on another.
  2. Add a short caption. Check contrast, alignment, spacing and spelling.
  3. Export a final copy in the format requested by your teacher.
  4. Before uploading to an image-hosting or sharing platform, check the audience, permission settings, image rights and whether personal information appears in the image.
Practice task: Create a school-awareness poster using one background, one graphic and a heading. Submit both the exported image and a short note listing the edits you made.
Remember: Keep the original file. Use images you created, have permission to use, or that are appropriately licensed.
🎨 MISSION 02

Make information pop

UNIT 7

2. Visual message design and infographics

Covers: principles of visual message design, drawing and painting, and infographic design.

Core principles

  • Purpose: decide the one message the audience should remember.
  • Hierarchy: make the title most noticeable, followed by key facts and details.
  • Contrast: use readable text/background combinations.
  • Alignment and spacing: line up related items and leave enough empty space.
  • Consistency: use a small, coordinated set of fonts, colors and icon styles.
  • Accuracy: verify figures and identify the source of information.

Make an infographic step by step

  1. Choose a focused topic and audience.
  2. Collect three to five verified facts and record their sources.
  3. Arrange the information into a title, short sections and a clear conclusion.
  4. Sketch a layout before using the drawing, shape, text and icon tools.
  5. Use simple charts or symbols only when they make information easier to understand.
  6. Proofread, check contrast and export in a suitable format.
Practice task: Design a one-page infographic about responsible digital citizenship. Include a clear title, three practical tips, one visual, and a small source note.
🌐 MISSION 03

Build for the web

UNIT 8 · UNIT 16

3. Online platforms and basic web design

Covers: online platforms for ICT content development; web design principles; website workflow; templates and online WYSIWYG website creators.

Key concepts

An online platform provides tools to create, publish, share or manage content. A template is a pre-designed layout. A WYSIWYG editor (“what you see is what you get”) lets users arrange content visually instead of writing every line of code.

Plan and build a simple page

  1. Plan: define the audience, purpose and main action the visitor should take.
  2. Outline: list the sections, such as Home, Lessons, Activities and About.
  3. Choose a template: pick one that is readable and works on mobile screens.
  4. Add content: write clear headings, short paragraphs, helpful links and meaningful image descriptions.
  5. Design: keep navigation consistent, use readable text and provide enough spacing.
  6. Preview: test the page on a narrow screen and a wider screen. Check links, spelling and image loading.
  7. Publish carefully: confirm that the content is appropriate for public viewing and that no private student details are exposed.

Website design checklist

  • Can visitors understand the page purpose quickly?
  • Can users find lessons without unnecessary clicks?
  • Are colors and text easy to read?
  • Do links and buttons work, and are they clearly labeled?
  • Does the page avoid publishing private information?
Practice task: Sketch a three-page learning website (Home, Tutorials, About). Label the navigation and describe what each page contains before building it in an available platform.
☁️ MISSION 04

Organize and share smartly

UNIT 8

4. Cloud computing and file management platforms

Covers: cloud computing, file management, organizing files and sharing resources.

Understand the basics

Cloud computing provides computing resources or files through networked services. Cloud file storage allows users to save, organize and access files across supported devices. Access depends on the service, account and internet connection.

Organize a project folder

  1. Create a main folder with a clear project name.
  2. Make subfolders such as Lessons, Images, Activities and Final Submissions.
  3. Use descriptive filenames, for example Unit7_Infographic_Draft1 rather than newfile2.
  4. Upload the correct files and wait until the service confirms completion.
  5. Open or preview the uploaded files to make sure they are not damaged or incomplete.

Share safely

  1. Choose a file or folder and open its sharing settings.
  2. Give access only to the people who need it. Prefer named recipients over public links for classwork.
  3. Choose view, comment or edit access according to the task.
  4. Do not share passwords or confidential student information.
  5. Review permissions after the collaboration ends and keep a backup of important work.
Practice task: Draw a folder tree for a group infographic project and write which team members should have view, comment or edit permission for each folder.
🧠 MISSION 05

Turn ideas into visuals

UNIT 9

5. Online visualization and presentation tools

Covers: mind mapping, mapping tools, online presentations and animation.

A. Create a mind map

  1. Put the main topic in the center.
  2. Add branches for the main ideas, then smaller branches for examples or evidence.
  3. Use short keywords instead of long paragraphs.
  4. Use colors or icons consistently to group related concepts.
  5. Check that the relationships between ideas make sense.

B. Use a mapping or visualization tool

  1. Decide what needs to be represented: places, relationships, processes or data.
  2. Choose a suitable visualization rather than using a map or chart just for decoration.
  3. Add a clear title, labels and a legend when needed.
  4. Check the source and accuracy of any location or data you include.
  5. Review readability and avoid revealing private locations or personal details.

C. Build a presentation with animation

  1. Write one main idea per slide and place the conclusion near the end.
  2. Use a consistent theme, large readable text and high-quality visuals.
  3. Add citations for borrowed facts, images and quotations.
  4. Use animation sparingly to reveal steps or emphasize an important point.
  5. Preview the slide show, test media and check the order before presenting.
Practice task: Create five slides explaining a digital-safety topic. Include a title slide, three content slides, a summary slide and sources. Use no more than one purposeful animation style.
🤝 MISSION 06

Create together

UNIT 10

6. Collaborative development of ICT content

Covers: team structure and dynamics for ICT content development.

Organize a team

A team works best when members understand the shared goal, responsibilities, deadlines and method for reviewing work. Roles may include coordinator, researcher, writer, designer, fact-checker and presenter. One person may hold more than one role in a small team.

Collaborative workflow

  1. Agree on the goal, audience, deliverables and deadline.
  2. Break the project into small tasks and assign an owner to each one.
  3. Use a shared task list and agreed file-naming rules.
  4. Keep drafts in a shared folder with appropriate access permissions.
  5. Give feedback that is specific, respectful and connected to the task requirements.
  6. Have a member other than the original writer check facts, spelling, accessibility and citations.
  7. Confirm that everyone agrees on the final version and submit it in the required format.
Practice task: Make a responsibility table for a four-person ICT project. Include each person's role, task, deadline and how the team will confirm completion.
Good practice: Credit each member's contribution, resolve disagreements respectfully and never remove another person's work without discussion.
